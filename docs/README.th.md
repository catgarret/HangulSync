HangulSync เป็นแอปเมนูบาร์สำหรับ macOS
ช่วยลดปัญหาตัวอักษรฮันกึลแยก (`ㅎㅏㄴㄱㅡㄹ`)
ระหว่างการใช้รีโมตเดสก์ท็อป

แอปจะซิงค์สถานะการป้อนภาษาเกาหลีและอังกฤษ
ระหว่าง Mac สองเครื่อง
เครือข่ายเดียวกันใช้ Bonjour
และเครือข่ายต่างกันสามารถใช้ Tailscale

## คุณสมบัติ

- **ซิงค์สองทางแบบเรียลไทม์**
  การเปลี่ยนแหล่งป้อนข้อมูลถูกส่งต่อทันที
- **ค้นหาอัตโนมัติ**
  - เครือข่ายเดียวกัน:
    ค้นหาผ่าน **Bonjour**
    และรองรับ AWDL P2P Wi-Fi เมื่ออยู่ใกล้กัน
  - คนละเครือข่าย:
    หาก **[Tailscale](https://tailscale.com)** ทำงานอยู่
    จะตรวจหาอุปกรณ์ใน tailnet เดียวกันทุก 30 วินาที
- **เลือกตามภาษา**
  หากไม่มีวิธีป้อนข้อมูลเดียวกัน
  จะใช้วิธีป้อนข้อมูลสำหรับภาษาเดียวกัน
- **ป้องกันลูป**
  การเปลี่ยนแปลงที่มาจากรีโมต
  จะไม่ถูกส่งซ้ำ
- **เบาและทำงานเบื้องหลัง**
  ควบคุมจากเมนูบาร์
  เลือกแสดงหรือซ่อนไอคอน Dock ได้
  และรองรับเปิดอัตโนมัติเมื่อเข้าสู่ระบบ
- **รองรับหลายภาษา**
  ไทย, English, 한국어, 日本語, 简体中文, 繁體中文, Русский, Italiano
- **ทำงานเฉพาะระหว่างเซสชันระยะไกล**
  ซิงค์เมื่อแอปอย่าง Jump Desktop, Screen Sharing, Screens,
  TeamViewer, AnyDesk หรือ RustDesk ทำงานอยู่
  สามารถเลือกโหมดเปิดตลอดได้จากเมนู
- **อนุมัติการเชื่อมต่อ**
  การเชื่อมต่อใหม่จะไม่แลกเปลี่ยนสถานะการป้อนข้อมูล
  ก่อนผู้ใช้อนุมัติ
- **รีเลย์อินเทอร์เน็ตแบบเข้ารหัส**
  Mac ที่จับคู่แล้วใช้ ntfy พร้อมการเข้ารหัสจากต้นทางถึงปลายทาง
  เมื่อไม่มีการเชื่อมต่อโดยตรง

## การติดตั้ง (ทั้งสองเครื่อง)

> ไม่ต้อง build
> ดาวน์โหลด `HangulSync.zip` ล่าสุดจาก
> [Releases](https://github.com/catgarret/HangulSync/releases/latest) แล้ววางใน `/Applications`
> (เปิดครั้งแรก: คลิกขวา → เปิด)

สามารถคัดลอก `HangulSync.app` ที่ build แล้วไปใช้ได้เลย

```bash
git clone https://github.com/catgarret/HangulSync.git
cd HangulSync
./install.sh
```

ต้องมี Xcode Command Line Tools (`xcode-select --install`)

1. เมื่อเปิดครั้งแรก
   ให้ **อนุญาตการเข้าถึงเครือข่ายท้องถิ่น**
2. คลิกไอคอน `⇄한` / `⇄A` บนเมนูบาร์
   แล้วเปิด **เปิดอัตโนมัติเมื่อเข้าสู่ระบบ**

## การจับคู่ครั้งแรกและข้อความ Keychain

1. เปิด HangulSync บน Mac ทั้งสองเครื่อง
2. กด **จับคู่ Mac เครื่องใหม่** ในการตั้งค่าของ Mac เครื่องใดเครื่องหนึ่ง
3. ตรวจสอบว่าทั้งสองเครื่องแสดงรหัสหกหลักเดียวกัน แล้วอนุมัติทั้งสองเครื่อง
4. หาก macOS ขอสิทธิ์เข้าถึง Keychain สำหรับเข้าสู่ระบบ
   ให้ตรวจสอบว่าชื่อแอปคือ HangulSync
   ใส่รหัสผ่านเข้าสู่ระบบของ Mac แล้วเลือก **อนุญาตเสมอ** หรือ **อนุญาต**

ใส่รหัสผ่านเฉพาะในหน้าต่าง Keychain ของ macOS ไม่ใช่ในหน้าต่าง HangulSync
หากยกเลิก การจับคู่แบบปลอดภัยและรีเลย์อินเทอร์เน็ตจะไม่ทำงาน

## เมนูบาร์

| ไอคอน | ความหมาย |
|---|---|
| `⇄한` / `⇄A` | กำลังซิงค์ (ภาษาปัจจุบัน: เกาหลี/อังกฤษ) |
| `⏸한` / `⏸A` | หยุดชั่วคราว |
| ไอคอนจาง | สแตนด์บาย (ไม่มีเซสชันระยะไกล) |
