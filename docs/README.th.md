แอปเมนูบาร์ขนาดเล็กที่**ซิงค์แหล่งป้อนข้อมูลภาษาเกาหลี/อังกฤษระหว่างเครื่อง Mac แบบเรียลไทม์** แก้ปัญหาตัวอักษรฮันกึลแตก (자소 분리) ภาษาป้อนข้อมูลไม่ตรงกัน และปุ่ม modifier ค้าง ที่พบบ่อยเมื่อใช้โปรแกรมรีโมตเดสก์ท็อปอย่าง **Jump Desktop**, Screens หรือการแชร์หน้าจอ

เมื่อสลับภาษาบน Mac เครื่องหนึ่ง เครื่อง Mac ที่เชื่อมต่อทั้งหมดจะสลับตามทันที **ไม่ต้องตั้งค่าใด ๆ ไม่ต้องกรอก IP**

## คุณสมบัติ

- 🔄 **ซิงค์สองทางแบบเรียลไทม์** — การเปลี่ยนแหล่งป้อนข้อมูลถูกส่งต่อทันที
- 🌐 **ค้นหาอัตโนมัติ ไม่ต้องตั้งค่า**
  - เครือข่ายเดียวกัน: ค้นหาผ่าน **Bonjour** (รองรับ AWDL P2P Wi-Fi เมื่ออยู่ใกล้กัน)
  - คนละเครือข่าย: หาก **[Tailscale](https://tailscale.com)** ทำงานอยู่ จะค้นหาอุปกรณ์ใน tailnet เดียวกันโดยอัตโนมัติ (ทุก 20 วินาที)
- 🧠 **จับคู่อัจฉริยะ** — หากอีกเครื่องไม่มีวิธีป้อนข้อมูลแบบเดียวกัน จะจับคู่ตามภาษาแทน
- 🔁 **ป้องกันลูป** — การเปลี่ยนแปลงที่มาจากรีโมตจะไม่ถูกส่งซ้ำ
- 🖥 **เฉพาะเมนูบาร์** — ไม่มีไอคอนใน Dock ทำงานเงียบ ๆ เบื้องหลัง รองรับเปิดอัตโนมัติเมื่อเข้าสู่ระบบ
- 🌍 **รองรับหลายภาษา** — ไทย, English, 한국어, 日本語, 简体中文, 繁體中文, Русский, Italiano
- 🎯 **ทำงานเฉพาะระหว่างเซสชันระยะไกล** — ซิงค์เฉพาะเมื่อใช้แอปรีโมตเดสก์ท็อป เช่น Jump Desktop, Screen Sharing, Screens, TeamViewer, AnyDesk, RustDesk (เปลี่ยนเป็นเปิดตลอดได้จากเมนู)
- ☁️ **รีเลย์อินเทอร์เน็ต** — แม้ไม่มี Tailscale หากเครื่อง Mac ทั้งสองเคยเชื่อมต่อกันโดยตรงครั้งหนึ่ง หลังจากนั้นจะซิงค์อัตโนมัติจากทุกที่

## การติดตั้ง (ทั้งสองเครื่อง)

สามารถคัดลอก `HangulSync.app` ที่ build แล้วไปใช้ได้เลย

```bash
git clone https://github.com/catgarret/HangulSync.git
cd HangulSync
./build.sh
cp -R build/HangulSync.app /Applications/
open /Applications/HangulSync.app
```

ต้องมี Xcode Command Line Tools (`xcode-select --install`)

1. เมื่อเปิดครั้งแรก ให้**อนุญาตการเข้าถึงเครือข่ายท้องถิ่น**
2. คลิกไอคอน `⇄한` / `⇄A` บนเมนูบาร์ → เปิด**เปิดอัตโนมัติเมื่อเข้าสู่ระบบ**

## เมนูบาร์

| ไอคอน | ความหมาย |
|---|---|
| `⇄한` / `⇄A` | กำลังซิงค์ (ภาษาปัจจุบัน: เกาหลี/อังกฤษ) |
| `⏸한` / `⏸A` | หยุดชั่วคราว |
| ไอคอนจาง | สแตนด์บาย (ไม่มีเซสชันระยะไกล) |
