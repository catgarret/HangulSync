Крошечное приложение для строки меню, которое **синхронизирует корейский/английский источник ввода между компьютерами Mac в реальном времени**. Устраняет «рассыпающийся» хангыль (자소 분리), рассинхронизацию языка ввода и залипание модификаторов при работе через **Jump Desktop**, Screens и другие средства удалённого доступа.

Переключите язык ввода на одном Mac — все подключённые Mac мгновенно переключатся. **Никакой настройки, никаких IP-адресов.**

## Возможности

- 🔄 **Двусторонняя синхронизация в реальном времени**
- 🌐 **Автообнаружение без настройки**
  - Одна сеть: обнаружение через **Bonjour** (вблизи — также AWDL P2P Wi-Fi)
  - Разные сети: если запущен **[Tailscale](https://tailscale.com)**, узлы вашего tailnet находятся автоматически (опрос каждые 20 с)
- 🧠 **Умный фолбэк** — если на другом Mac нет того же метода ввода, подбирается по языку
- 🔁 **Защита от зацикливания** — применённые извне изменения не рассылаются повторно
- 🖥 **Лёгкое фоновое приложение** — управление из строки меню, значок в Dock по желанию, автозапуск при входе
- 🌍 **Локализованный интерфейс** — Русский, English, 한국어, 日本語, 简体中文, 繁體中文, ไทย, Italiano
- 🎯 **Работает только во время удалённого сеанса** — синхронизация активна, пока используется Jump Desktop, Общий экран, Screens, TeamViewer, AnyDesk, RustDesk и др. (в меню можно включить постоянный режим)
- ☁️ **Интернет-реле** — даже без Tailscale: если два Mac хотя бы раз соединялись напрямую, дальше они синхронизируются откуда угодно автоматически

## Установка (на оба Mac)

Можно просто скопировать собранный `HangulSync.app`.

```bash
git clone https://github.com/catgarret/HangulSync.git
cd HangulSync
./install.sh
```

Требуются Xcode Command Line Tools (`xcode-select --install`).

1. При первом запуске **разрешите доступ к локальной сети**
2. Нажмите значок `⇄한` / `⇄A` в строке меню → включите **Запускать при входе**

## Строка меню

| Значок | Значение |
|---|---|
| `⇄한` / `⇄A` | Синхронизация активна (текущий ввод: корейский/английский) |
| `⏸한` / `⏸A` | Пауза |
| Тусклый значок | Ожидание (нет удалённого сеанса) |
