HangulSync — приложение для строки меню macOS.
Оно уменьшает распад хангыля (`ㅎㅏㄴㄱㅡㄹ`)
при работе через удалённый рабочий стол.

Приложение синхронизирует корейский и английский режимы ввода
на двух Mac.
В одной сети используется Bonjour, а между разными сетями — Tailscale.

## Возможности

- **Двусторонняя синхронизация в реальном времени**
- **Автоматическое обнаружение**
  - Одна сеть: обнаружение через **Bonjour** (вблизи — также AWDL P2P Wi-Fi)
  - Разные сети:
    если запущен **[Tailscale](https://tailscale.com)**,
    узлы того же tailnet проверяются каждые 30 секунд
- **Подбор по языку**
  если такого же метода ввода нет,
  используется метод для того же языка
- **Защита от зацикливания**
  применённые извне изменения не рассылаются повторно
- **Лёгкое фоновое приложение**
  управление из строки меню, значок в Dock по желанию
  и автозапуск при входе
- **Локализованный интерфейс**
  Русский, English, 한국어, 日本語, 简体中文, 繁體中文, ไทย, Italiano
- **Работает только во время удалённого сеанса**
  синхронизация активна, пока запущен Jump Desktop, Общий экран,
  Screens, TeamViewer, AnyDesk или RustDesk.
  Постоянный режим можно включить в меню
- **Подтверждение подключения**
  новая связь не передаёт состояние ввода
  до подтверждения пользователя
- **Зашифрованный интернет-ретранслятор**
  связанные Mac используют ntfy со сквозным шифрованием,
  когда прямое подключение недоступно

## Установка (на оба Mac)

> Сборка не нужна.
> скачайте свежий `HangulSync.zip` из
> [Releases](https://github.com/catgarret/HangulSync/releases/latest) и поместите в
> `/Applications`.
> При первом запуске нажмите правой кнопкой и выберите **Открыть**.

Можно просто скопировать собранный `HangulSync.app`.

```bash
git clone https://github.com/catgarret/HangulSync.git
cd HangulSync
./install.sh
```

Требуются Xcode Command Line Tools (`xcode-select --install`).

1. При первом запуске **разрешите доступ к локальной сети**
2. Нажмите значок `⇄한` / `⇄A` в строке меню.
   Включите **Запускать при входе**.

## Первое подключение и запрос Keychain

1. Запустите HangulSync на обоих Mac.
2. Нажмите **Подключить новый Mac** в настройках любого из них.
3. Проверьте, что на обоих Mac показан одинаковый шестизначный код,
   затем подтвердите подключение на обоих устройствах.
4. Если macOS запросит доступ к связке ключей входа,
   убедитесь, что указано приложение HangulSync.
   Введите пароль текущего Mac и выберите **Разрешать всегда** или **Разрешить**.

Вводите пароль только в системном окне Keychain, а не в окне HangulSync.
При отмене безопасное подключение и интернет-ретранслятор работать не будут.

## Строка меню

| Значок | Значение |
|---|---|
| `⇄한` / `⇄A` | Синхронизация активна (текущий ввод: корейский/английский) |
| `⏸한` / `⏸A` | Пауза |
| Тусклый значок | Ожидание (нет удалённого сеанса) |
